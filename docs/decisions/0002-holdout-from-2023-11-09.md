# 0002 — Holdout: everything from 2023-11-09 is sealed, once

**Status:** accepted, 2026-11-15 (owner).

**Decision.** All data dated on or after 2023-11-09 is a one-shot holdout. The date is fixed, not
a rolling window. It applies to every source (Massive, Sharadar, anything downloaded later).

**How.** Two layers: the Massive holdout files are physically separate in `MarketData/sealed/`,
and the data layer raises on any holdout date unless run with `--unseal` and
`KINN_UNSEAL_TOKEN`. Only the owner unseals; every unseal is logged.

**Why.** The pre-2023-11-09 window has been searched heavily by the earlier builds (see
`docs/retired/`). The holdout is the only untouched evidence left; one look is all it is good for.

**Consequences.** No build step, audit or test loads holdout dates. Sharadar files contain
holdout rows, so they are filtered at ingestion and never written to processed data.
